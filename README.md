# Delhi NCR Urban Change Intelligence (2024–2026)

Satellite-based urban and land-cover change detection across Delhi NCR using
Sentinel-2 imagery, a Siamese U-Net change detection model, and Monte Carlo
Dropout uncertainty quantification.

**Status: Phase 0 — Project Initialization**

Full methodology, results, and reproduction steps will be documented here as
the project develops. See `PROJECT_STATE.md` for current progress.

## Study Area
Delhi, Gurugram, Noida, Ghaziabad, Faridabad

## Stack
Python, PyTorch, Google Earth Engine, rasterio, geopandas, Streamlit

## Compute
Training runs on Google Colab (free-tier GPU). See `notebooks/00_colab_setup.ipynb`.
